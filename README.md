# Project Description: Price Tracker Using C

Price Tracker is a console-based application developed using the C programming language. Its main purpose is to help users manage and monitor the prices of different products. It allows users to add product details, view all available products, search for products using their unique IDs, update prices, and check whether a product has reached its target price.

The application uses a simple menu-driven interface implemented with switch-case statements. Structures and arrays are used to store product information, while user-defined functions make the program modular and easy to understand. File handling is used to save product records permanently in a text file, allowing users to access previously stored information.

**Key Features:**
1. Add new products with their details.
2. View all stored products and prices.
3. Search products using their IDs.
4. Update existing product prices.
5. Check whether products have reached their target prices.
6. Save and retrieve records using file handling.

**Technologies and Concepts Used:**
- Programming Language: C
- Compiler: GCC
- IDE: Visual Studio Code
- Concepts: Variables, arrays, strings, structures, loops, conditional statements, switch-case, functions, and file handling.

**Conclusion:**

This project demonstrates the practical application of fundamental C programming concepts in a real-world scenario. It improves programming logic, problem-solving skills, and understanding of modular programming and file management.
